# 0.0.12

## Improvements

- Use standard `v0.0.x` Release tags to keep same-day versions in the correct order on GitHub.
- Preserve in-app upgrades for older installations through a compatibility release with the same installer.

## Bug fixes

- Select the highest stable version by its version number, regardless of the release list order or the legacy latest-release entry.

# 0.0.12 中文更新日志

## 改进

- Release 改用标准 `v0.0.x` 标签，让 GitHub 同日发布的版本按正确顺序显示。
- 保留使用同一安装包的兼容发布，旧版仍可通过应用内更新完成升级。

## 错误修复

- 按版本号选择最高正式版本，不受发布列表顺序或旧版更新入口的影响。
