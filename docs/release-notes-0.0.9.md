# 0.0.9

## Features

- Check for updates once at startup by default. Turn this off in Settings → About if preferred.
- Show a dismissible notice when a newer release is available, with a shortcut to the update controls. Downloads and installation still require your action.

## Improvements

- Remove the five-minute memory trend, including its sample storage and chart rendering, to simplify the overview and eliminate ongoing chart work.
- Check for updates in the background without delaying the window or loading the settings page. Network failures stay quiet and leave manual checking available.

## Updating

In 0.0.8, open Settings → About → Check for updates to download 0.0.9. Then choose Install update and approve the installation. The existing installation folder, settings, and startup preferences are preserved.

# 0.0.9 中文更新日志

## 功能

- 默认在每次启动时检查一次更新，可在“设置 → 关于”关闭。
- 发现新版本时显示可关闭的提示，并提供更新入口。下载和安装仍由用户点击执行。

## 改进

- 移除最近五分钟的内存趋势图及其采样存储、绘制逻辑，精简概览并去掉持续的图表开销。
- 后台检查更新，不等待网络才显示窗口，也不提前加载设置页。网络失败时不弹窗，仍可手动检查更新。

## 更新方式

在 0.0.8 中打开“设置 → 关于 → 检查更新”下载 0.0.9，然后点击“安装更新”并完成授权。升级沿用原安装目录，保留设置和开机启动选项。
