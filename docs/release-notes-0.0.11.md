# 0.0.11

## Bug fixes

- Fix the app failing to reopen after an in-app update with an access-denied error. The desktop Shell now reopens the app with ordinary user permissions.
- Wait briefly for the previous instance to exit when reopening after setup, keeping existing settings and startup preferences.

# 0.0.11 中文更新日志

## 错误修复

- 修复应用内更新完成后因“拒绝访问”无法重新打开的问题，改由桌面 Shell 以普通用户权限重开。
- 安装结束后重开时，短暂等待旧实例退出，保留设置和开机启动选项。
