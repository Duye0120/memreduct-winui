# 0.0.13

## Improvements

- Introduce a compact memory overview with usage, capacity figures, a cleanup button and the last cleanup result in one place.
- Move Memory and Settings into underlined navigation below the title bar and remove the obsolete sidebar toggle.
- Keep recent cleanups and process usage collapsed by default. Process data still loads only when requested.
- Refine settings spacing, dropdown arrows and numeric inputs. Percentage and interval controls share aligned input and unit columns, with room to edit four-digit minute values.
- Simplify About and updates: keep the version, update controls, original-author credit and project links together without extra dividers.
- Preserve cleanup animations, warning colors, cleanup options, fullscreen protection, tray controls and existing preferences.

## Bug fixes

- Keep settings controls within the visible area when the window is widened or text is enlarged.
- Remove unwanted content borders when cleanup history or process details are expanded.

## Updating

Open Settings and choose Check for updates, or download the installer below. Upgrades reuse the existing installation folder and retain personal settings. Older applications can still upgrade through the retained compatibility release.

Based on Henry++'s [Mem Reduct](https://github.com/henrypp/memreduct), under GPL-3.0.

# 0.0.13 中文更新日志

## 改进

- 采用紧凑的内存概览，将使用率、容量、清理按钮和上次清理结果集中展示。
- 将“内存 / 设置”改为标题栏下方的下划线导航，移除旧侧栏按钮。
- 最近清理和进程占用默认收起；进程数据仍仅在需要时读取。
- 优化设置间距、下拉箭头和数字输入框。百分比与时间间隔的输入框、单位列保持对齐，并为四位分钟数预留完整编辑空间。
- 精简“关于与更新”：将版本号、更新入口、原作者说明和项目链接集中排列，移除多余分隔线。
- 保留清理动画、预警颜色、清理选项、全屏保护、托盘操作和原有偏好设置。

## 错误修复

- 修复拉宽窗口或放大文字后，设置控件超出可见区域的问题。
- 移除清理记录或进程详情展开后多余的内容边框。

## 更新方式

在“设置”中点击“检查更新”，或下载下方安装包。升级沿用原安装目录并保留个人设置；旧应用仍可通过保留的兼容发行版继续升级。
